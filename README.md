# YouTube 竞品视频挖掘

一个 Python / Tkinter 桌面工具。填写品牌、选择年份后点击一次“开始采集并自动导出”，程序依次完成半年分段搜索、公开视频详情核验、历史红人频道补扫、公开字段补齐和结果导出。

## 一键使用

1. 安装 Python 3.10 或以上版本，保留 Tcl/Tk，并确保能够访问 YouTube。
2. 下载并解压项目，双击 `启动竞品红人挖掘.bat`。首次启动会自动安装采集依赖，需要联网。
3. 填写品牌名称，选中需要的年份。官方 YouTube 账号可选；填写后会排除该频道发布的视频。
4. 点击“开始采集并自动导出”，等待完成。无需手动分批或点击频道补扫；内部达到单批额度时会自动继续。
5. 完成后自动打开结果目录，包含 `视频明细.xlsx`、`视频描述.csv` 和 `品牌年度汇总.xlsx`。

视频明细按品牌分组，第一列是品牌；同一视频匹配多个品牌会分别列出。默认要求视频标题包含品牌名，并以视频详情中的实际发布日期筛选年份。描述完整保存到描述表。

程序先搜索品牌、品牌加年份以及每半年的时间范围，再自动补扫当前选择品牌中重复出现的前 50 个频道。时间范围查询用于扩大发现，并不替代实际发布日期核验。浏览器搜索结果和频道公开数据无法保证全站完整。未填写官方账号时无法排除其官方视频。

采集任务、失败和已发现的视频保存在本地 SQLite 台账；网络中断、访问验证、手动停止或局部失败会保存已收集的结果并自动导出可用部分。保持相同设置再次点击开始可继续；访问受限需要等网络恢复后继续。未公开或未取得的字段不会伪造为零。

## 迁移和隐私

开源包不包含品牌配置、历史台账、采集结果、业务模板或密钥。换电脑需安装 Python、访问 YouTube 并配置品牌；若需携带历史结果，将私有台账及导出文件通过可信渠道自行转移。可在本地放置未提交的 `初始配置.json` 预填品牌配置，格式为 `{"brands": [{"name": "Example", "official": "", "terms": ""}]}`。请勿将配置或业务数据提交到公开仓库。

默认输出在项目目录的 `导出文件/采集结果_批次号/`。Excel 可选使用本地 `竞品youtube视频数据.xlsx` 的原有 11 列样式；开源包使用内置样式。地区来自频道公开信息；播放和粉丝数为采集时的数据，部分显示为近似数。匹配品牌不表示商业合作已确认。
