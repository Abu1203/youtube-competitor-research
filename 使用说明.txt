YouTube 竞品视频采集与历史台账
============================

启动
双击“启动竞品红人挖掘.bat”。若旧版窗口仍开着，请关闭后重新启动。
对方电脑需要先安装 Python 3.10+（含 Tcl/Tk；建议勾选 Add Python to PATH），并能正常访问 YouTube。
默认是网页采集（免 Key）；开源版不附带 lib，首次使用请先安装依赖。“安装或更新采集依赖.bat”用于安装/更新库，不安装 Python 本身。

品牌设置
每个品牌有独立的品牌名、官方 YouTube 账号、补充搜索词输入框。
开源版首次启动只有一个空白品牌框，不包含真实品牌配置。品牌名必填。官方账号可选，用于排除官方频道发布的视频；支持 @账号、/@账号、/channel/UC… 和 /user/…。
补充搜索词可填产品名或别名，用逗号分隔；品牌名会自动作为搜索词。
点击“＋ 新增品牌”可增加输入框；“移除品牌框”只移除配置，不删除历史数据。

采集
选择 2024、2025、2026 年，点击“开始采集”。默认每词搜索 100 条线索，当次最多新读取 500 条详情，均可调整。
年份关键词用于扩充搜索，最终按视频详情日期筛选。公开搜索不能保证完整发现所有合作视频。
历史视频按视频 ID 去重：再次搜到时复用已存详情，并可以出现在当次结果中，不重复访问完整视频详情。
勾选“刷新历史指标”才重新获取动态数据；每个历史批次的指标快照会保留。
点击“补扫历史红人频道”可进一步列出所填品牌的历史频道视频、Shorts、直播，查找提及品牌的内容。
网页详情间隔约 1.5–3 秒，出现限流或验证时停止并保存进度。
结果默认全部纳入台账，没有审核状态；无关视频可根据简介自行删除。

表格与导出
界面和 Excel 都固定为以下 11 列，顺序不增加、不改变：
视频内容、视频链接、发布时间、观看量、点赞量、评论量、频道名称、网红频道链接、粉丝数、地区、类型。
“一键导出当次 Excel”导出当前采集批次已收到的全部记录；采集中途也可导出。
导出保存到“导出文件”子文件夹，默认使用内置空白模板和日期格式 yyyy/m/d。可在本地添加“竞品youtube视频数据.xlsx”定制样式；该文件不会纳入版本控制。
发布时间写成真正的 Excel 日期，两列链接可点击，数值保持数值。为方便阅读，列宽适当展开。

历史台账
“历史台账”可按品牌、年份、关键词或采集批次查看，支持导出当前历史视图。
“删除选中”会从显示结果和后续导出中移除，并留下视频 ID 删除标记，避免下次重新抓入。
勾选“查看已删除”后可以“恢复选中”。
台账保存在“竞品视频台账.sqlite3”，请保留该文件。首次升级会自动迁移旧版 JSON 数据，旧文件仍保留。
可以点击“补齐历史缺失字段”，读取公开页面补充地区和未取得的计数。

地区和其他字段
地区优先读取频道关于页公开国家，并转换为 US、FR、NZ 等两位代码；每个频道会缓存一次结果。
没有公开地区的频道显示“未公开”；网络失败显示“获取失败”，可再次补齐或手动填写。
评论数缺失时会读取评论区公开总数；明确取得 0 时写 0，不把缺失当成 0。
未公开的其他计数显示“未公开”。粉丝数、观看量等是采集时公开值，并非视频发布当年的值。
网页发布时间按 UTC 日期显示，可能与北京时间差一天。
类型根据标题及频道简介规则填写，也可手动修改地区/类型；人工修改会在以后刷新时保留。

可选官方 API
只有切换为“官方 API”才需要 API Key；API Key 不保存到台账。
